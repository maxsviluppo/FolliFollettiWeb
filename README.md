# sito-home

Home page con hero full-screen, navbar allo scroll, nuvole e card orizzontali.

## Avvio

```bash
npm install
npm run dev
```

Apri http://localhost:3200

## Struttura

- Hero a tutto schermo dal top
- Menu + logo dopo scroll oltre l'hero
- Bordo nuvole puffose sotto l'hero
- Sezione gradiente bianco → azzurro con 5 box scroll orizzontale
